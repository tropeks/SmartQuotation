# H2.2 — Apontamento de Produção — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Capture real labor hours per OF operation (apontamento) and, on OF closure, write immutable observations plus a per-operation `ActualRate` aggregate that H2.3 will consume.

**Architecture:** Additive enrichment of the existing roteiro (the engine already computes hours; we persist them through `ItemOperation` → snapshot → `OFOperation`). New models live in `apps.production`: `ProductionEntry` (many per operation, summed), `ProductionObservation` (immutable, written at closure), `ActualRate` (online Welford aggregate, upserted at closure). Closure logic hooks into the existing `concluir`/`transition` atomic block. `pricing_engine` is untouched.

**Tech Stack:** Django 5.2 · django-tenants (TenantTestCase) · PostgreSQL · Decimal money/hours · HTMX templates.

```python
def log_production_entry(of_operation, operator, hours_hh, hours_hm=0,
                         entry_date=None, notes="", request=None):
    """Registra apontamento de tempo numa operação de OF liberada/em produção."""
    from datetime import date as _date
    status = of_operation.item.ordem.status
    if status not in (STATUS_LIBERADA, STATUS_EM_PRODUCAO):
        raise ValidationError(
            f"Apontamento só é permitido em OF liberada ou em produção (status atual: {status})."
        )
    if hours_hh is not None and hours_hh < 0:
        raise ValidationError("Horas não podem ser negativas.")
    entry = ProductionEntry.objects.create(
        of_operation=of_operation,
        operator=operator,
        hours_hh=hours_hh,
        hours_hm=hours_hm or 0,
        entry_date=entry_date or _date.today(),
        notes=notes or "",
    )
    if request is not None:
        log_access(request, "appoint", entry, {
            "of_id": of_operation.item.ordem_id,
            "of_operation_id": of_operation.pk,
            "hours_hh": str(hours_hh),
        })
    return entry
```

```python
def _update_actual_rate(operacao: str, ratio):
    """Upsert online (Welford) do agregado ActualRate de uma operação. Retorna o ActualRate."""
    from decimal import Decimal
    ar = ActualRate.objects.select_for_update().filter(operacao=operacao).first()
    if ar is None:
        ar = ActualRate(operacao=operacao)
    r = float(ratio)
    n = ar.sample_count + 1
    mean = float(ar.mean_ratio)
    m2 = float(ar.m2)
    delta = r - mean
    mean += delta / n
    m2 += delta * (r - mean)
    variance = m2 / n if n >= 1 else 0.0
    stddev = math.sqrt(variance) if variance > 0 else 0.0
    cv = (stddev / mean) if (mean > 0 and n >= 2) else 0.0
    cv = min(max(cv, 0.0), 1.0)
    confidence = (1 - cv) * min(n / 20.0, 1.0)
    ar.sample_count = n
    ar.mean_ratio = Decimal(str(round(mean, 4)))
    ar.m2 = Decimal(str(round(m2, 6)))
    ar.confidence = Decimal(str(round(confidence, 4)))
    ar.save()
    return ar
```

Note: this MUST be called within a transaction (it uses `select_for_update`). The closure hook in Task 6 runs inside `transition`'s `@transaction.atomic`. The test calls it inside the test's transaction (TenantTestCase wraps each test in a transaction), so `select_for_update` is valid there too.

```python
def _close_out_observations(of):
    """No fechamento: grava observação imutável e atualiza ActualRate p/ cada operação apontada."""
    from decimal import Decimal
    ops = OFOperation.objects.filter(item__ordem=of).prefetch_related("entries")
    for op in ops:
        if op.estimated_hh <= 0:
            continue
        if not op.entries.exists():
            continue  # leniente: sem apontamento -> sem observação
        actual_hh = op.actual_hh
        ratio = (Decimal(actual_hh) / Decimal(op.estimated_hh)) if op.estimated_hh else Decimal("0")
        ProductionObservation.objects.create(
            operacao=op.codigo_op, ordem=of, of_operation=op,
            estimated_hh=op.estimated_hh, actual_hh=actual_hh,
            ratio=ratio.quantize(Decimal("0.0001")),
        )
        _update_actual_rate(op.codigo_op, ratio)
```
